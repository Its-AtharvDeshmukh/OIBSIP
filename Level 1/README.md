## 📌 Overview
Level 1 establishes the foundational skills of web development. This directory contains responsive web pages built using clean, modern **HTML5**, **CSS3**, and **Vanilla JavaScript** following industry best practices for accessibility and mobile responsiveness.

---

## 🚀 Key Features & Implementation
* **Responsive Layouts**: Designed mobile-first using modern CSS Flexbox and Grid to ensure fluid scaling across mobile, tablet, and desktop viewports.
* **Semantic HTML**: Strict adherence to semantic tags (`<header>`, `<main>`, `<section>`, `<footer>`) for improved screen reader compatibility and SEO.
* **Interactive Elements**: Dynamic user interactions implemented cleanly using native vanilla JavaScript event listeners without heavy external framework dependencies.
